## Редакторские уточнения

- `virtsaputki`: исходное `uretha` исправлено на **`urethra`**.
- `lonkkaluu`: вместо краткого `coxae` — **`os coxae`**.
- `sepelvaltimo` (ед. ч.): вместо `arteriae coronariae` (мн. ч.) — **`arteria coronaria`**.
- `paksusuoli`: **`intestinum crassum`** обозначает толстую кишку; `colon` — её более узкую часть.
- `kylkiluut` (мн. ч.): **`costae`**, ед. ч. `costa`.
- `ruoansulatus`: нормализовано написание из `Ruuansulatus`.
- `virtsaneritys`: `diuresis` — международный медицинский термин; `diureesi` — его финская форма.
- Для `häpyluu`, `istuinluu`, `suoliluu` приведены полные варианты `os pubis`, `os ischii`, `os ilium`; краткие исходные формы сохранены в `latin_original`.
- `keuhko`/ `keuhkot`, `luu`/ `luut`: исходные множественные формы сохранены в примечаниях.
