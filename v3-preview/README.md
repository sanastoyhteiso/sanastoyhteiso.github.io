# Sanastoyhteisö 3.0 — изолированный пилот на рабочем домене

Предложенный адрес: https://sanastoyhteiso.github.io/v3-preview/ .
Решение владельца 07.11.2026: сначала пилот отдельным URL без замены / .
Контрольный main и резервная ветка backup/production-before-v3-20261104: d29813cf409af9dc60804105ca3141f98ec12fcd.

Границы первого этапа:
* Утверждённый интерфейс FI/EN/RU, учебные карточки, тесты, словарь и Mediatri из PR #9; вход через рабочую Firebase Authentication.
* Результаты и собственные слова сохраняются в **отдельной** локальной области пилота по UID на конкретном устройстве. Они не синхронизируются и не переносятся в основной сайт.
* Не загружаются V3 remote sync, legacy account settings и home-refresh. Google Drive-синхронизация, профили, Firestore writes и миграция выключены. Firebase Authentication имеет общую для домена сессию.
* Владелец с подтверждённым Google custom claim admin=true видит учебный интерфейс. ВАЖНО: GitHub Pages — публичный статический ресурс; JavaScript-gate не заменяет серверный доступ. Реальную безопасность личной информации обеспечивают Firestore Rules.
* Service worker — network-only и применяется только к /v3-preview/; offline-ready пока НЕ подтверждено. Старый root SW может обслужить самое первое обращение старого браузера, поэтому тестировать онлайн, а затем отдельно на iOS12.
* Общий серверный журнал отсутствует: admin_metrics/current был не найден в live проверке RUN-121. Не показывать ложные «0 ошибок» или «ОК».
* Новый ZIP-деплой, перепубликация Firestore Rules, изменение тарифа и пользовательских данных запрещены.

Условия следующего этапа:
положительный/отрицательный реальный Firestore Rule test для administrator/normal/anonymous, private backup→readback→isolated restore, два устройства, затем отдельное разрешение на включение V3 cloud sync. Полный переход на / только после отдельной приёмки.
