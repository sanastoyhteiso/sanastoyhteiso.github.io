# RUN-146 — экзаменационный словарь Riveria: Päästä varpaisiin (2014)

## Решение об использовании латыни

Латинские названия являются **подсказками внутри карточек**, а не новым направлением перевода и не четвёртым языком интерфейса. Направления обучения остаются FI↔RU и FI↔EN. После «Показать ответ» видны перевод, латинское название (когда есть), простое объяснение на финском и его русский смысловой перевод. В «Словаре» объяснения видны сразу, а поиск работает в том числе по латыни и по тексту объяснения.

## Источник и ограничения

- Главный источник охвата: пользовательский экзаменационный план Riveria по книге *Päästä varpaisiin* (издание 2014). **Текст самой книги не получен**; определения — самостоятельно написанные учебные пояснения, а не цитаты страниц учебника. Латинский список — ранее предоставленные пользователем 61 термин из [чернового PR №16](https://github.com/sanastoyhteiso/sanastoyhteiso.github.io/pull/16), 37 связаны с исходными ID и 24 новые.
- Базовый `data.js` содержит 1296 слов (проверенный SHA `fa65cf3ba0683309050a7dc729d6898699a63bbc`). **Не перезаписываем этот файл:** дополнительный ES5-файл `riveria-anatomy-exam.js` подключается сразу после него. Имеющиеся 37 терминов обогащаются `la`, `examNoteFi`, `examNoteRu`, `examTopics` по тем же ID; новые термины получают стабильные ID `T90xxx` без конфликтов с выученными словами.
- Разделы доступны отдельной группой в выпадающем списке «Тема» в **Карточки / Тесты / Словарь**. Сохраняются все прежние 66 тематических категорий и возможность выбрать «Все темы».
- Переключение экзаменационной темы фильтрует по `examTopics` без изменения исходной категории слова, его пользовательского прогресса, сохранённого перевода, Auth, V3 облачных событий или правил Firestore.

## Пределы и проверка

- Пример: `sydän — сердце — cor`; подсказка FI о расположении в грудной клетке и RU перевод. `keuhko — лёгкое — pulmo`; альвеолы и газообмен. `iho — кожа — cutis`; слои `epidermis, dermis, subcutis`. У других теоретических карточек латинское поле необязательно.
- До выпуска обязательны автоматические проверки на настоящий `data.js`: 10 селекторов, 61 латинская запись, 37 ссылок на старые ID, 24 новых латинских слова, 0 конфликтующих ID, не менее 4 карточек на каждую тему, полный FI/RU смысл, отсутствуют EI, поиск по латыни, раскрытие пояснений только после переворота карточки, обратная связь теста, сохранение существующих `learned`.
- На iPhone после выпуска проверить меню категорий, одну карточку по каждому разделу, латынь внутри объяснения и совпадение «Выучено» на устройствах. **Никаких обязательных новых ролей, Firebase тарифов или структур Firestore**.
