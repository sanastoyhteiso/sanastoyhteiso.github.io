# RUN139 — безопасная проверка структуры legacy JSON

Задание владельца называлось RUN138; этот номер уже занят E2E-тестом. История TASK138 сохранена, реализация данного задания — TASK139, DRAFT PR9.

API: `require('./backup-v3/legacy-json-structure.cjs').inspect(kind, jsonText)`.
Принимает только primitive strings: kind `score` или `scope`, JSON одного плоского объекта. Без SDK, сети, чтения файлов, миграции, облачных записей или подключения к сайту. Все текущие испытания исключительно искусственные; реальные Events!F не читались и требуют отдельного разрешения.

| Ограничение | Значение |
| --- | --- |
| UTF-8 размер одного JSON | 4096 байт |
| Глубина | 1: только корневой объект |
| Количество свойств | не более 6 |
| Длина декодированной строки | не более 64 UTF-16 code units |
| Объектов за вызов | ровно 1; массивы/пакетный импорт запрещены |

score требует correct, wrong, seen, last (неотрицательные safe integers); learned (boolean) и learnedUpdatedAt (такое же целое) распознаются независимо и необязательны. Их отсутствие явно видно по отсутствию поля в отчёте; НИКОГДА не выводить learned из счётчиков. scope требует value (исторические mine/all по family.js:setScope) и updatedAt (safe integer). Значения не возвращаются. Это структурный контракт, не доказательство достоверности или арифметической согласованности истории.

Успешный результат: фиксированные флаги, разрешённый kind, количество полей, канонически упорядоченные разрешённые названия и типы. automaticMigrationAllowed=false и sourceIntegrityVerified=false всегда. Нет счётчиков ответов, дат, learned true/false или выбранной настройки, ID/адресов/слов/сырого JSON. Ошибка: только ok=false и фиксированный code. Неизвестные поля, включая prototype-ключи, дубли декодированных ключей, вложенность, массивы, неверные типы/границы, лишний текст блокируют весь результат; частичного отчёта нет. Объекты/Proxy/getters/toJSON не принимаются.

Проверка: `node --test release-checks/v3-legacy-json-structure.test.cjs`. 10 локальных тестов PASS: позитивные схемы, обе ручные отметки/неполная пара, одинаковый отчёт при различных значениях, скрытые/private canaries в неизвестных полях, prototype-ключи, escaped duplicate keys, лимиты UTF-8/вложенности/свойств/строк, malformed JSON, unsafe numbers, отсутствие coercion и стабильность порядка. Обязательный CI step добавлен без continue-on-error.
