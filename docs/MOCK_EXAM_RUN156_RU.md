Владелец запросил сразу две функции. Этап 1: единый выбор направления `auto, fi-ru, ru-fi, fi-en, en-fi` во всех трёх новых учебных режимах, не теряя существующее поведение первого режима. Основной язык вопроса — источник направления, второй — целевой язык, мелким читаемым шрифтом. Автоматический режим FI→RU для финского сайта, RU→FI для русского, EN→FI для английского. Для английских учебных пояснений **не выдавать FI/RU за EN**: 30 ранее составленных исходных утверждений переводить отдельно и точно, новые задания строить на уже имеющихся EN-переводах терминов, объяснения сохранять FI/RU; отсутствие EN-пояснения помечать, а не выдумывать.

Этап 2: отдельная вкладка «Экзамен / Koe / Exam» в основном меню. **40 страниц-заданий, по 10 каждого из четырёх существующих видов, случайно перемешанных; десять экзаменационных тем, по одному заданию каждого вида на каждую тему**. В экзамене только выбор направления (без «другой вопрос» и без выбора темы), проверка и переход к следующему. Ответы сохраняются только в оперативной памяти текущей сессии; правильные варианты/объяснения не раскрывать до завершения. После 40 ответов — количество очков, процент, PASS при >=80% (32/40) и FAIL при менее 80%, разбор ошибок. Все ответы в четырёхсоставных заданиях допускают доли балла, чтобы 80% честно вычислялись. Без изменения прежней статистики прогресса, Firebase, Firestore, профилей, пользовательских слов и резервов.
