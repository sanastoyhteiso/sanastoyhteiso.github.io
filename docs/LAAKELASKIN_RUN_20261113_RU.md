# RUN-LÄÄKELASKIN-20261113 — учебный калькулятор Lääkelaskut

Дата: 13.11.2026. Проект: Sanastoyhteisö 3.0, репозиторий `sanastoyhteiso/sanastoyhteiso.github.io`.

## НАЧАЛ — запрос владельца
Разработать удобный калькулятор на основе уже существующего раздела `laakelaskut.html`, где есть 47 задач и 68 отдельных вопросов Riveria. Требования: внешний вид обычного калькулятора с крупными цифровыми кнопками; перевод г/мг/мкг, л/мл и других совместимых единиц; формулы для таблеток, жидких лекарств, скорости инфузий и объёмов; учебный пошаговый разбор; полноэкранное открытие на телефонах; сохранение текущего задания при открытии и закрытии калькулятора.

## Сделано в рабочей ветке
- Создана ветка `feat/laakelaskin-study-calculator-20261113` от `main`.
- Создан `laakelaskin-core.js` — независимые арифметические вычисления без eval, конверсия единиц с запретом неверного преобразования массы в объём и IU в мг, десять учебных схем расчёта.
- Создан `laakelaskin.html` — самостоятельная страница с цифровой клавиатурой, вкладками «Счёт», «Единицы», «Формулы», выводом результатов и пояснений.
- В `laakelaskut.html` добавлена кнопка открытия модального калькулятора. На телефонах — полный экран; на больших экранах — плавающее окно с кнопкой увеличения. Тренировочная задача при открытии калькулятора не сбрасывается.
- Возврат числового результата из окна калькулятора в поле ответа через `postMessage` с проверкой `origin` и `source`. Автоматическая проверка ответа НЕ запускается.
- Обновлён `sw.js`: офлайн-кэш включает обе новые страницы/скрипты, версия rc43.
- Добавлен набор регрессионных проверок `release-checks/laakelaskin-20261113.test.cjs`.

## Проверки и ограничения
- Синтаксис основного вычислителя и обоих встроенных контроллеров проверен в JavaScript-движке.
- Проведена независимая локальная проверка 21 утверждения: арифметика, дробные значения, конверсия, пример таблеток, жидкости, дозы по массе, капли, смешивание, проценты, совместимость встраивания, сервис-воркер. Результат: 21/21 PASS.
- Это **учебный математический инструмент**, не медицинское назначение, не проверка допустимости доз, деления таблеток, состава препаратов или оборудования.
- В реальном браузере на iOS/старом iPad визуальная/сенсорная проверка пока не проведена. Node тест в GitHub Actions необходимо подтвердить отдельно.
- При расчёте массы в объём обязательно указывать концентрацию (мг/мл). IU не переводить в мг без данных вещества.
- Округление по заданию, не использовать округление автоматически для реальных лекарств.
