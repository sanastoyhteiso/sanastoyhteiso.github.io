# RUN172 — инструкция подключения словарей в «О проекте»

## НАЧАЛ — 09.11.2026 · Europe/Helsinki

**Запрос владельца.** Новые зарегистрированные пользователи Sanastoyhteisö 3.0 получают пустой экран карточек/словаря и думают, что сайт пустой. Владелец просит написать на `about.html` инструкции на финском, английском и русском о подключении готовой базы и подписке на другие словари; допускает идею автозагрузки, но просит обдумать лучший способ.

**Проверено по текущему коду** `main` commit `8cea45f414336d1d16d55509ca4bd7dfb0796b70`:
- `family.js`: начальный `scope:{value:'mine',updatedAt:0}`; `sharedEnabled()` показывает стандартную библиотеку только в режиме `all` вошедшего пользователя. `app.js` показывает `D.terms` только в этом режиме.
- `app.js`: меню `Данные` → панель `Мой словарь` → `Показывать слова` → `Мой словарь + библиотека Riveria`; смена `family-scope` вызывает `RS_FAMILY.setScope(...)` и сохраняет настройку в рамках аккаунта. Не нужно импортировать файл или подключать Google Drive для встроенных слов.
- `community.js`: `Библиотека` → `Найти словари` → `Подключить` на публичной опубликованной коллекции; `Обновить подписки` для новых версий. Каталог может быть пуст; он **отличен от встроенной Riveria базы**.
- `i18n.js`: проверены существующие названия кнопок FI/EN/RU, включая `Tiedot/Data`, `Näytä sanat/Show words`, `Omat sanat + Riveria-kirjasto/My words + Riveria library`, `Etsi sanastoja/Find dictionaries`, `Liitä/Connect`.
- `index.html` уже содержит внизу ссылку `О проекте` → `about.html`; сама страница автоматически показывает FI/EN/RU по системному языку либо вручную выбранному. Исправлять основную навигацию не требуется.

**Реализация:** дописать только три локализованных раздела в `about.html`, прямо в начале страницы перед описанием возможностей, с инструкцией для 0 слов, четырьмя шагами подключения Riveria и отдельным абзацем о публичной «Библиотеке» и необязательности Google Drive. Новый CSS ограничен общим оформлением нумерованного списка `ol`. Никакого изменения логики, автоматической активации, Firebase, Cloudflare, словарных данных, прогресса, приватности, дизайна главного приложения либо хранения аккаунтов.

**Выбор:** вместо автоподключения по умолчанию (потребовало бы изменения пользовательских предпочтений, отдельной проверки уже существующих аккаунтов и офлайн-логики) реализована запрошенная справка. Возможный следующий этап отдельно: контекстная ссылка «Как подключить словари» рядом с пустым состоянием для новых пользователей, либо явное предложение включить Riveria в первом входе. **Ни одно из этих изменений в RUN172 не делается.**

**Резерв:** `backup/pre-dictionary-help-run172-20261109` от `8cea45f414336d1d16d55509ca4bd7dfb0796b70`. Рабочая ветка `docs/dictionary-onboarding-run172-20261109`. Добавлен `release-checks/about-dictionary-start-run172.test.cjs` и отдельный шаг preflight CI; обязательные прежние проверки не отключать.
