# Правила Firebase для включения V3 на основном сайте

Проект: `riveria-sanasto-community-test` — это **старый действующий Firebase**, в котором зарегистрированы существующие пользователи Sanastoyhteisö. Изолированная разработка ранее работала в ДРУГОМ проекте `sanastoyhteiso-v3-development`.

## Когда применять

- Прежде проверить, что единый интерфейс и Firestore-клиент PR №9 прошли CI и визуальный тест. Отдельный development Firebase менять не требуется.
- В Firebase Console открой **только** Firestore → Rules проекта `riveria-sanasto-community-test`.
- Скопируй полный нынешний текст правил в отдельный резервный файл до любого изменения.
- Проверь поиском `sync_v3`: если такой блок уже есть, не добавляй второй одноимённый. Вместо этого нужно сравнить существующие разрешения и заменить только старые правила `sync_v3`.
- Если `sync_v3` отсутствует, вставь ВНУТРИ уже существующего `match /databases/{database}/documents` код из файла `release-checks/firestore-v3-production-additive.rules.txt` перед финальным catch-all `match /{document=**}`.
- Не заменяй все правила кодом V3 Development: это нарушит существующие профили и пользовательские библиотеки.
- Опубликуй только после review содержимого; проверь на тестовом владельце read/create и отказ чужому аккаунту. Не меняй production Firebase Auth и не удаляй старых пользователей.

## Почему нужна ручная публикация

GitHub Pages публикует HTML/JavaScript, но не может изменять Firestore Security Rules без отдельного административного доступа. В этом чате доступ только к GitHub, не к Firebase Console. Никакие секреты или service account ключи в репозитории не нужны.

## Что будет до публикации

- Старые функции сайта продолжат работу с прежними данными и Google Drive.
- При попытке добровольно включить V3 приложение сделает проверку доступа к Firestore. Если правила не разрешают `sync_v3`, V3 не включится и прежний профиль не будет очищен.
- После публикации каждый пользователь включит V3 самостоятельно; ему будет сделана локальная копия старой истории.

## Что проверить после

- Войти в старый Google-аккаунт на `https://sanastoyhteiso.github.io/`.
- Включить V3 в специальной строке статуса, получить `0 в очереди`.
- Ответить на термин, проверить на другом устройстве, убедиться в отсутствии двойного счёта.
- В «Новое слово» найти `peseytyminen`, добавить существующее слово в «Мои находки», не создавая W-дубля.
- Убедиться, что старые библиотека, Mediatri, переводы и тесты открываются.

Внимание: этот файл ещё необходимо сравнить с АКТУАЛЬНЫМИ опубликованными production Rules — GitHub не раскрывает их серверное состояние.
