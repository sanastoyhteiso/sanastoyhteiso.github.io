## Почему нельзя просто заменить index.html или слить PR #8

- PR #8 добавляет материалы в staging и сам по себе не заменяет production index.html.
- Classic V3 — полноценные старые экраны, но отдельно работающий офлайн-демонстратор без реальной авторизации и синхронизации.
- Study V3 — настоящий Firestore/IndexedDB, но отдельный интерфейс, где пока нет полного Mediatri, тестов, библиотек и других функций production.
- Production использует Firebase riveria-sanasto-community-test и старые пользовательские UID; новая база разработчика — sanastoyhteiso-v3-development. Переключение Firebase без переноса пользователей разорвёт связь с их результатами.
- Действующие app.js/family.js используют per-UID localStorage, community.js — Google Drive, sw.js — старый Cache Storage. Не подменять эти хранилища автоматически.
