Только сервер с проверенным JWT, `admin=true`, конкретным `SUPERADMIN_UID` и ограниченным Google IAM правом `firebaseauth.users.get` может читать только нужные поля. Модуль только read-only. Отдельная возможность администрирования аккаунтов требует самостоятельного согласования и server-audit.
- Безопасность: backend защита и учёт доступа обязательны; если нет учётных данных/миграции D1, UI честно показывает «Не подключено». Никаких реальных пользовательских email и ответов в тестах.
