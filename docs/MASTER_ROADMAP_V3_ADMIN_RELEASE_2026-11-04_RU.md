## 1. Принципы и непреложные ограничения

1. Сайт ученика максимально прост: учёба, карточки, тесты, словарь, Mediatri, библиотека, личные данные. **Никаких внутренних пояснений Firebase, V3, отладки и админ-виджетов в «Данные».**
2. Раздел админа **отдельный маршрут `/admin/`**. Кнопка видна только при подтверждённой сервером Firebase роли `admin=true`, но **скрытая ссылка не является защитой**: Firestore Rules и backend проверяют права на каждом защищённом запросе.
3. Никаких приватных учебных ответов, личных слов, медицинских сведений, e-mail и токенов в админском журнале. Минимальная обезличенная диагностика, GDPR/policy/retention, пропуск персональных строк и full URL.
4. **Рабочие аккаунты/UID и история других учеников не обнуляются** даже если владелец согласен начать собственную статистику с нуля. Firestore, Google Drive, IndexedDB, localStorage, резервные копии не удалять.
5. Использовать тестовый репозиторий и отдельную тестовую Firebase для изменений; production только через проверенный release PR и явно согласованное переключение.
6. Данные диагностического мониторинга, если недоступны/устарели, выводятся как «Нет данных», а не 0; «ОК» только с доказанной исправностью самого мониторинга и сервисных проверок.
7. GitHub PAT, Firebase service account, Admin SDK ключи НИКОГДА не помещать в GitHub Pages/ZIP/публичную репу/чат. Клиентская загрузка ZIP сама не публикует код.
8. При невозможности безопасной бесплатной серверной реализации явно сравнить альтернативы (например, GitHub App с защищённым backend или ручное подтверждение PR с одним пакетом); не подключать оплату без согласия.
9. Совместимость: iPhone, Android, настольный браузер и **iPad mini 3 / Safari iOS 12.5.x**, ES5 там, где требуется, доступность кнопок и нижнего меню.
