# Sanastoyhteisö 3.0 — «Мои находки» (закрытый тест)

**Только staging:** рабочий `https://sanastoyhteiso.github.io/`, его `main`, Firebase `riveria-sanasto-community-test` и старый Google Drive не изменять.

## Что реализовано

1. Ввод FI в «Записать новое слово» проверяет полный публичный каталог и личные слова. Пробелы, регистр и Unicode NFC нормализуются. Точные совпадения показываются первыми; общий термин T предпочтительнее личной копии W.
2. При точном совпадении кнопка создания блокируется. Выбирается существующий ID; в личную облачную историю отправляется ТОЛЬКО событие `collection_set` (list=`finds`, added=true/false, topic=practice/study/other, note до 350 символов). В каталоге второй термин не возникает.
3. Похожие словоформы — только предложения, не автоматическое объединение. Владелец выбирает правильную карточку.
4. При отсутствии совпадения личный ID W детерминированно выводится из Firebase UID + нормализованного финского названия посредством SHA-256. Один аккаунт на двух устройствах получает один и тот же ID. Разные переводы с одним ID блокируются конфликтным тестом, а не молча перезаписываются.
5. События принадлежат только подтверждённому владельцу и сначала атомарно пишутся в отдельный IndexedDB V3; облачная запись подтверждается после успешной доставки. Удаление из «Моих находок» сохраняет явный tombstone, не удаляет карточку и историю ответов.
6. Фильтр «Мои находки» работает поверх оригинальных ID; заметка и тема отображаются только авторизованному пользователю. Старое избранное независимо от новых находок.

## Разрешения в новой тестовой Firebase

- Прежние правила опубликованы пользователем и НЕ менялись программно.
- Новый файл **только для проекта `sanastoyhteiso-v3-development`**: `staging/backend/firestore.v3-development-with-finds.rules`. Он сохраняет исходные правила `firestore.v3-development-with-sync-demo.rules` и добавляет минимальный проверенный `collection_set`.
- Обновлённые правила требуется опубликовать вручную владельцу после зелёного emulator CI. Не менять старый Firebase и не публиковать в рабочий проект.
- До публикации расширенных правил новые отметки «Мои находки» не будут подтверждаться облаком; не обещать успешную синхронизацию.

## Тест перед выпуском

1. На отдельном test Pages открыть `/riveria-sanasto-community-test/v3-classic/auth-pilot/study-v3.html`. Google-вход — только новый V3 Development.
2. Ввести `peseytyminen`, найти существующее слово и нажать «В мои находки», записав категорию «Практика» и вымышленную заметку без персональных данных.
3. Убедиться, что количество терминов в общем каталоге не увеличилось, а отметка появилась в фильтре «Мои находки». Повторное добавление не создаёт событие при полностью совпадающих данных.
4. На другом устройстве под тем же аккаунтом проверить ту же запись и заметку. На другом тестовом аккаунте её быть не должно.
5. Ввести ещё не встречавшееся вымышленное слово FI/RU/EN — создать новую личную карточку, повторить ввод на другом устройстве и проверить отсутствие дубля.
6. Проверить офлайн: добавить словарную находку, перезапустить страницу в том же авторизованном профиле, восстановить сеть, отправить очередь. Проверить отсутствие двойного счёта и сохранение ответов.
7. Убрать слово из находок: оно должно исчезнуть только из личной подборки, но сохранить исходную карточку, избранное и статистику.

## Ограничения

- Пока не добавлены полноценные пользовательские рубрики/папки, перенос находок между курсами, редактирование общего словаря и серверный поиск по морфологии.
- Схожесть словоформ эвристическая; решение об объединении принимает человек.
- SHA-256 требует Web Crypto. Если устройство не поддерживает безопасное вычисление, создание личного слова блокируется; слабый хэш не используется.
- Сведения о клиентах, пациентах и коллегах не вносить.
- Не объединять PR №8 с production `main` до проверок на iPhone, старом iPad, ПК и второго аккаунта, резервного восстановления и отдельного разрешения владельца.
